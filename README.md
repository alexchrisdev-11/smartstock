# SmartStock

SmartStock is a modern inventory management system designed to manage your products, stock, and suppliers in one place.

## Tech Stack

- **Frontend (Week 1):** React (JavaScript), Vite, CSS3
- **Backend (Upcoming):** Node.js, Express.js, MongoDB

> **Note:** This repository represents **Week 1** of a multi-week full-stack build. Currently, the initial React client is set up using Vite. Backend services with Node/Express and database integration with MongoDB will be introduced in upcoming phases.

## Getting Started

Follow these steps to run the project locally on your machine:

### Prerequisites
- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- npm (bundled with Node.js)

### Installation & Local Development

1. Navigate to the project directory:
   ```bash
   cd smartstock-client
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Open your browser and visit the local URL shown in your terminal (typically `http://localhost:5173`).

### Available Scripts

- `npm run dev` — Launches the Vite development server with Hot Module Replacement (HMR).
- `npm run build` — Builds the application for production in the `dist` directory.
- `npm run preview` — Locally previews the production build.
